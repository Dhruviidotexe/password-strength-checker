## About

Password Strength Checker is a web-based cybersecurity tool that analyzes
password strength in real time and provides security recommendations based on
password length, character diversity, entropy, repetition, sequential
patterns, and common password patterns.

The application is designed with privacy in mind and does not store user
passwords.

## Features

- Real-time password strength analysis
- 0–100 strength score
- Password strength classification
- Character-type analysis
- Password entropy estimation
- Common password detection
- Sequential pattern detection
- Repeated-character detection
- Personalized security recommendations
- Show/hide password functionality
- Responsive UI
- Privacy-focused password handling
- Animated interactive interface

## Security & Privacy

- Passwords are not stored.
- Passwords are not written to files.
- Passwords are not stored in localStorage.
- Passwords are not sent to third-party password services.
- The original password is not returned by the analysis API.

## Disclaimer

This project is intended for educational and security-awareness purposes.
The strength score and entropy values are heuristic estimates and do not
guarantee that a password is secure against every real-world attack.
